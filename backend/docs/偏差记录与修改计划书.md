## 四、本轮（第 21 轮）部署验证发现并修复的代码缺陷

**这是本文最有价值的部分**：11 个缺陷**全部只在真实部署暴露**，1111 个单测一个都测不到。
根因是单测全部用本地等价实现（`InMemoryCache` / `NumpyVectorStore` / `Bm25SparseIndex` / SQLite），
真实部署走 Redis / Milvus / ES / PostgreSQL。

| # | 缺陷 | 症状 | 修复文件 |
| --- | --- | --- | --- |
| D-01 | `asyncio.run()` 与 redis 连接池不兼容 | `RuntimeError: Event loop is closed`，所有对话 503 | `app/core/asyncbridge.py`、`app/adapters/cache.py`、`app/adapters/sparse_index.py` |
| D-02 | `MilvusVectorStore` 从不创建集合 | `DescribeCollectionException: can't find collection`，reindex 336 条全失败 | `app/adapters/vector_store.py` |
| D-03 | 缺 `aiohttp` | `ValueError: You must have 'aiohttp' installed to use AiohttpHttpNode` | `requirements.txt` |
| D-04 | `elasticsearch>=8.12` 装成 9.x | `BadRequestError(400, media_type_header_exception, ... compatible-with=9)` | `requirements.txt` |
| D-05 | pydantic-settings 对 list 强制 `json.loads` | 启动即 `SettingsError: error parsing value for field "llm_domain_allowlist"` | `app/core/config.py` |
| D-06 | `REPO_ROOT` 在容器里算成 `/` | `PermissionError` 建 `/backend/.local`；导入报「商家材料包缺少必需文件」 | `app/core/config.py`、`app/api/v1/kb.py` |
| D-07 | compose 给所有镜像加 docker.io 前缀 | `docker.io/quay.io/...` 地址不存在，compose up 直接失败 | `docker-compose.yml` |
| D-08 | MinIO 官方镜像已从 Docker Hub 下架 | `Error response from daemon: denied` / `manifest unknown` | `docker-compose.yml` |
| D-09 | 前端镜像用 node:20 但代码要 `node:sqlite` | `ERR_UNKNOWN_BUILTIN_MODULE: No such built-in module: node:sqlite` | `frontend/Dockerfile`、`docker-compose.yml` |
| D-10 | nginx `add_header` 覆盖而非继承，首页丢全部安全头 | `/` 与 `/index.html` 响应里没有 CSP / `X-Frame-Options` / `X-Content-Type-Options` / `Referrer-Policy` | `frontend/deploy/nginx.conf`、`frontend/deploy/nginx.docker.conf` |

每条缺陷的完整堆栈、根因、修法与「为什么不能反过来改」都写进了

### 5.2 标准部署步骤（已实测）

```bash
# 1. 起容器（首次会拉镜像 + 构建，约 10~20 分钟，取决于网络）
cd backend
docker compose --profile core up -d --build

# 2. 建表（6 个迁移版本）
docker compose exec -T app alembic upgrade head

# 3. 种子数据（6 个坐席分组 + 6 条转人工规则 + 5 个渠道配置，幂等）
docker compose exec -T app python scripts/seed_reference_data.py

# 4. 知识库导入（336 条：FAQ 126 / POLICY 136 / PRODUCT 74）
curl -X POST http://127.0.0.1:8000/internal/v1/kb/import \
  -H "X-Internal-Token: test_internal_token" -H "Content-Type: application/json" \
  -d '{"source_path":"__all__","created_by":"deploy"}'

# 5. 重建索引（写进 Milvus + ES，336 向量 + 336 稀疏）
curl -X POST http://127.0.0.1:8000/internal/v1/kb/reindex \
  -H "X-Internal-Token: test_internal_token" -H "Content-Type: application/json" \
  -d '{"rebuild_vectors":true,"rebuild_sparse":true}'

# 6. 端到端冒烟（19 条断言，退出码 0 = 全绿）
docker compose exec -T -w /app -e PYTHONPATH=/app app python /app/scripts/smoke_e2e.py
```
