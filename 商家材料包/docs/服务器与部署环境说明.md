## 2. 网络与白名单

### 2.1 网络架构

```
                    ┌─────────────────────────┐
   公网（平台回调） │  SLB / API 网关（HTTPS）│
                    └───────────┬─────────────┘
                                │
                    ┌───────────▼─────────────┐
                    │  DMZ 子网 10.0.1.0/24   │
                    │  Agent 应用层 ECS        │
                    └───────────┬─────────────┘
                                │（内网）
                    ┌───────────▼─────────────┐
                    │  应用子网 10.0.2.0/24   │
                    │  向量库 / PostgreSQL     │
                    └───────────┬─────────────┘
                                │
                    ┌───────────▼─────────────┐
                    │  数据子网 10.0.3.0/24   │
                    │  RDS / Redis（现有）     │
                    └─────────────────────────┘
```

### 2.2 IP 白名单规则

| 方向 | 来源 | 目标 | 端口 | 说明 |
|---|---|---|---|---|
| 入站 | 平台回调 IP 段 | SLB | 443 | 五渠道平台回调（IP 段由各平台公布，本店协助维护） |
| 入站 | 项目组办公网出口 IP | VPN 网关 | 443 | 联调访问，每环境最多 5 个 |
| 出站 | Agent 应用层 | 本店 API 网关 | 443 | 调用订单/物流/库存/商品/工单接口 |
| 出站 | Agent 应用层 | 各平台开放平台 | 443 | 发送客服消息 |
| 出站 | Agent 应用层 | 模型服务 | 443 | 大模型调用 |
| 禁止 | 任意 | 数据子网 | 3306/6379 | 应用层**不得直连**数据库，须经 API 网关 |

### 2.3 需项目组提供的白名单信息

| 项目 | 数量 | 说明 |
|---|---|---|
| 联调出口 IP | 每环境最多 5 个 | 需固定 IP，不接受动态 IP |
| 回调域名 | 1 个 | 必须是已备案的 HTTPS 域名 |
| 回调服务器 IP | 2 个 | 用于本店侧出站白名单 |

| 项目 | 内容 | 状态 |

| 本店主域名 | `wankeai.example.com` | ✅ 已注册、已备案 |

**备案要求**：

1. 中国大陆的服务器必须使用**已备案域名**，否则平台回调会被拦截。
2. 备案主体须与云账号主体一致；若项目组使用本店云账号（方案 A），可使用本店域名下的子域名，**免去重新备案**。
3. 备案审核周期约 **7–20 个工作日**（各省管局不同），**是部署方案的时间风险点**。
4. 若项目组使用自有域名，需自行完成备案，本店可提供备案流程咨询。

> **建议**：优先采用方案 A + 本店子域名，可节省 2–3 周的备案等待时间。

## 4. 安全合规要求

### 4.1 强制要求

| 要求 | 具体标准 | 责任方 |
|---|---|---|
| 传输加密 | 全链路 HTTPS（TLS 1.2+），禁止 HTTP 明文 | 项目组 |
| 数据加密 | 数据库敏感字段加密存储；备份加密 | 项目组 |
| 访问控制 | 最小权限原则；禁止应用层直连数据库 | 项目组 |
| 日志审计 | 接口调用日志留存 ≥6 个月；写操作日志 ≥1 年 | 项目组 |
| 数据脱敏 | 按《商家资料索取清单》第四节执行；日志禁止打印完整手机号/地址 | 项目组 |
| 漏洞管理 | 上线前完成一次渗透测试，高危漏洞须修复 | 项目组 |
| 密钥管理 | 禁止硬编码；使用 KMS 或环境变量注入 | 项目组 |
| 人员管理 | 联调人员签署《数据安全承诺书》；离职即回收权限 | 双方 |

### 4.2 数据存储位置

| 数据类型 | 存储位置 | 说明 |
|---|---|---|
| 知识库（商品/FAQ/政策） | 中国大陆境内 | 不含个人信息 |
| 会话记录 | 中国大陆境内 | 含脱敏后用户信息 |
| 用户个人信息 | **不落库** | 实时调用接口获取，用完即弃 |
| 向量库 | 中国大陆境内 | 知识向量，不含个人信息 |
| 备份 | 中国大陆境内 | 不出境 |

> **硬性约束**：**所有数据不得出境**。若项目组使用境外模型服务（如海外 API），需先将用户消息脱敏至不可识别个人身份后方可调用，且需经法务审核。

### 4.3 合规审查清单

项目组上线前需提供：

- [ ] 《数据安全承诺书》（已签署）
- [ ] 渗透测试报告（高危漏洞已修复）
- [ ] 数据流向图（证明数据不出境）
- [ ] 脱敏方案说明（含日志脱敏）
- [ ] 应急响应预案（含数据泄露处置流程）
- [ ] 项目结束后的数据删除方案

## 6. 例外情形

1. **云账号共享的边界**：若采用方案 A，本店提供 RAM 子账号，**不提供主账号**。子账号权限由本店按最小权限原则配置。
2. **带宽限制**：本店现有公网带宽为 10Mbps，若项目组压测超出该带宽，需提前 3 个工作日申请临时扩容。
3. **备案不可控**：备案审核由各省管局执行，本店无法承诺具体时长。
4. **跨境限制**：若项目组坚持使用境外模型服务，本店需经法务单独审核，且**不得传输任何未脱敏的用户信息**。
5. **现有资源占用**：1.2 节列出的现有资源已承载本店 ERP/OMS 业务，项目组**不得**直接使用，需申请新增资源或使用独立子网。
