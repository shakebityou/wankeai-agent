## 2. 产品安全与检测

### 2.1 GB 6675 玩具安全标准

**执行标准**：本店毛绒玩偶、挂件、抱枕类商品执行 **GB 6675《玩具安全》系列国家标准**，具体包含：

| 标准编号 | 标准名称 | 检测内容 |
|---|---|---|
| **GB 6675.1-2014** | 玩具安全 第 1 部分：基本规范 | 玩具安全的基本原则、标识要求、通用安全要求 |
| **GB 6675.2-2014** | 玩具安全 第 2 部分：机械与物理性能 | 结构安全、锐利边缘、小零件、绳索、折叠机构 |
| **GB 6675.3-2014** | 玩具安全 第 3 部分：易燃性能 | 材料燃烧速率、阻燃要求 |
| **GB 6675.4-2014** | 玩具安全 第 4 部分：特定元素的迁移 | 锑、砷、钡、镉、铬、铅、汞、硒等 8 种元素迁移限量 |

**适用说明**：

- 毛绒玩偶、挂件、抱枕按上述四项全项执行。
- 搪胶潮玩与盲盒属**收藏向产品**（标注 15 岁以上），同样按 GB 6675 做机械物理性能与特定元素迁移检测，不做「供 14 岁以下儿童使用」的玩具类目宣称。
- 婴幼儿专用品类（如安抚类产品）如涉及，另行执行 GB 31701《婴幼儿及儿童纺织产品安全技术规范》。

**检测频次**：每个生产批次均抽样送检，检测报告按批次留存，保存期限不少于 3 年。每半年做一次全项型式检验。

**消费者获取方式**：

- 店铺「资质证照」页面可查看近期检测报告。
- 消费者提供订单号，客服可调取对应批次的检测报告 PDF。
- 如对某项指标特别关注，可告知客服，由客服确认对应批次的检测数据。

**例外情形**：

- 检测报告按批次出具，**同一 SKU 不同批次的报告编号不同**，不能通用。
- 检测机构需为具备 CNAS/CMA 资质的第三方实验室。
- 如某批次检测不合格，立即下架该批次并启动召回，按《售后政策》4.4 条处理。

### 2.2 检测项目明细

**核心检测项目与限量要求**：

| 检测类别 | 检测项目 | 限量要求 | 依据 |
|---|---|---|---|
| **机械与物理性能** | 小零件测试 | 3 岁以下玩具不得存在可脱落小零件 | GB 6675.2 |
| | 锐利边缘/尖端 | 不得存在可触及的危险锐利边缘与尖端 | GB 6675.2 |
| | 缝纫强度 | 接缝在拉力测试下不破裂 | GB 6675.2 |
| | 填充物外露 | 正常使用与合理滥用后不得外露 | GB 6675.2 |
| | 绳带长度 | 符合年龄组别要求 | GB 6675.2 |
| **易燃性能** | 表面燃烧速率 | 毛绒类 ≤ 30 mm/s | GB 6675.3 |
| **化学性能** | 特定元素迁移（8 种） | 铅 ≤ 90 mg/kg、镉 ≤ 75 mg/kg、铬 ≤ 60 mg/kg 等 | GB 6675.4 |
| | 甲醛含量 | ≤ 20 mg/kg（婴幼儿类 ≤ 20 mg/kg） | GB 18401 |
| | 可分解致癌芳香胺染料 | 不得检出（≤ 20 mg/kg） | GB 18401 |
| | pH 值 | 4.0–8.5 | GB 18401 |
| | 异味 | 无刺激性异味 | GB 18401 |
| | 色牢度（耐水/耐汗渍/耐摩擦） | ≥ 3 级 | GB 18401 |
| **标识要求** | 适用年龄标注 | 必须明确标注 | GB 6675.1 |
| | 警示说明 | 3 岁以下需标注「小零件危险」 | GB 6675.1 |

**测试方法说明**：

- **拉力测试**：对小零件、眼睛、鼻子、纽扣等附件施加 70N 拉力并保持 10 秒，附件不得脱落。
- **合理滥用测试**：包含跌落、扭拧、拉伸、压力测试，模拟儿童正常使用与可预见的滥用。
- **填充物检测**：填充材料不得含金属杂质、尖锐物，不得使用工业废料。

**消费者告知话术**：

> 本店商品执行 GB 6675 玩具安全标准，每批次都做拉力、小零件、燃烧性能、特定元素迁移等检测，检测报告齐全，可在店铺资质页查看或向客服索取。

**例外情形**：

- 上述限量值引自国家标准，具体以**最新版标准**为准；标准更新后本文件同步修订。
- 搪胶与盲盒类为收藏向产品，部分检测项目（如缝纫强度）不适用，按材质特性执行对应项目。

## 3. 正品保障与鉴别

### 3.1 防伪码

**防伪机制**：本店毛绒玩偶、搪胶潮玩类商品配有**一物一码防伪标签**。

**防伪码位置**：

| 品类 | 防伪标签位置 |
|---|---|
| 毛绒玩偶 | 商品吊牌背面，或玩偶内侧洗标旁 |
| 挂件 | 吊牌背面 |
| 抱枕 | 吊牌背面 |
| 搪胶潮玩 | 彩盒底部或亚克力罩内侧贴纸 |
| 盲盒 | 单盒外包装封口处 |

**验证方式**：

1. **刮开涂层**：防伪标签上的银色涂层刮开后可见 16 位防伪码。
2. **扫码验证**：微信扫描标签上的二维码，跳转至官方验证页面。
3. **输入验证**：在官方验证页面输入 16 位防伪码，点击验证。
4. **查看结果**：
   - **正品**：显示「该防伪码首次查询，为正品」，同时显示商品名称与查询时间。
   - **已被查询过**：显示首次查询时间与次数，需警惕二次销售或仿冒。
   - **不存在**：显示「防伪码无效」，请立即联系客服。

**防伪码规则**：

- 每个防伪码**仅对应一件商品**，一物一码。
- 防伪码首次查询后会被记录，重复查询会提示首次查询时间。
- 防伪码不可重复使用，不可转让。

**例外情形**：

- **部分早期批次**（2025 年 6 月前）未配备防伪码，可凭吊牌与订单记录验证正品。
- **盲盒类**因随机性，防伪码位于外包装，拆封前请先扫码验证。
- 防伪标签**被人为破坏、撕除、涂改**的，无法验证，需联系客服核实订单记录。

**官方鉴别途径（按可靠性排序）**：

**假一赔十承诺**：

本店承诺**假一赔十**。若消费者对收到的商品有疑虑：

1. 联系客服，提供订单号与商品照片。
2. 客服核对出库批次并安排**官方鉴定**，费用由本店承担。
3. 经鉴定确认为仿冒品的，按商品实付金额的 **10 倍**赔偿，并承担全部鉴定与寄回运费。

- 鉴定需由**具备资质的第三方机构或品牌方**出具结论，消费者单方判断不作为认定依据。
- 商品已被**拆解、改造、水洗损坏**导致无法鉴定的，需先与客服协商替代核验方式。
- 跨渠道购买的商品（非本店渠道），本店不承担鉴别责任，可协助联系对应渠道。

**联名 IP**：

| IP 类型 | 授权期限 | 授权区域 | 授权品类 |
|---|---|---|---|
| 第三方动漫 IP | 按合同约定，通常 2–3 年 | 中国大陆 | 指定品类（毛绒玩偶、挂件） |
| 艺术家联名 | 按项目约定，通常 1 年 | 中国大陆 | 限量款（搪胶潮玩、盲盒） |
| 品牌跨界联名 | 按项目约定 | 中国大陆 | 指定系列 |

**授权使用规则**：

- 联名 IP 商品仅在**授权期限与授权区域内**销售。
- 联名 IP 商品的**设计稿需经版权方审核**后方可生产。
- 联名 IP 商品的**宣传素材**（图片、视频、文案）需经版权方审核。
- 授权到期后，剩余库存需按合同约定处理（销毁、去标识销售或续约）。
- 消费者**不得**将联名 IP 商品用于商业用途、二次创作或批量转售。

**商品标识**：商品主数据表（`data/商品主数据表.csv`）的「是否IP联名」字段标注该 SKU 是否为 IP 联名款（「是」/「否」）。

**例外情形**：

- **授权期限届满**的联名款会下架，已购商品不影响消费者正常使用。
- **授权区域外**的订单不发货（如联名款仅授权中国大陆，港澳台及海外不发货）。
- **非授权渠道**销售的联名款商品，本店不承担正品责任，将配合版权方维权。

| 证明类型 | 形式 | 可提供对象 | 说明 |

**无法提供原件的说明**：

- **联名 IP 授权书原件**涉及版权方的商业条款与保密约定，**不向个人消费者提供**。替代方案：① 提供隐去商务条款的授权摘要页；② 提供版权方在商品页面的官方授权标识；③ 通过平台「品牌授权」查询入口核验。
- **营业执照、生产许可证原件扫描件**涉及法人个人信息，个人消费者提供**隐去敏感信息的版本**。

**例外情形**：

- 平台、监管机构、司法机构依法调取时，本店提供完整授权文件。
- 企业采购客户在签署保密协议后，可查看授权摘要页。
- 授权文件涉及第三方版权方的保密义务，本店无权单方披露。

发现侵权的，本店将：① 固定证据（截图、公证）；② 向平台投诉下架；③ 发送律师函；④ 必要时提起诉讼。消费者如发现疑似侵权商品，可向客服举报，经核实后给予奖励。

### 6.3 数据与隐私合规

- 消费者个人信息（姓名、电话、地址）按《商家资料索取清单》第四节脱敏规则处理，客服系统仅展示脱敏后的信息。
- 智能客服的训练数据已做脱敏处理，不含完整手机号、订单号、身份证号、银行卡号。
- 不向任何第三方提供消费者个人信息，法律法规另有规定的除外。

### 6.4 例外情形

法律法规、监管要求与平台规则优先于本章约定。
